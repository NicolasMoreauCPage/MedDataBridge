Documentation technique de l'intégration IHE PAM (Profil France)

1. Architecture générale

  • Pipeline principal : app/services/transport_inbound.py
  • Validation : app/services/pam_validation.py
  • Routage métier : app/services/message_router.py
  • Handlers : app/services/pam.py
  • Fusion patients : app/services/patient_merge.py
  • Génération HL7 PAM : adapters/hl7_pam_fr.py

2. Pipeline de traitement

2.1. Entrée des messages

  • Réception HL7v2 via MLLP → on_message_inbound_async
  • Validation structurelle, journalisation, acquittement

2.2. Parsing des segments

  • Parseurs robustes : PID, PV1, ZBE, MRG, NK1, PD1
  • Support des répétitions et extensions locales

2.3. Validation métier

  • Validation IHE PAM (validate_pam), HL7 v2.5, configuration stricte/warn

2.4. Routage et gestion des mouvements

  • Routage par trigger (IHEMessageRouter), handlers dédiés
  • Gestion annulations, mises à jour partielles (Z99)
  • Persistance des contacts (NK1)

2.5. Fusions d'identités (A40)

  • Traitement MRG, ré-attribution, archivage, journalisation

3. Extensibilité et conventions

  • Parseurs factorisés (app/infrastructure/hl7/parsing.py)
  • Règles configurables (env : STRICT_PAM_FR, ENABLE_PAM_EXT, ...)
  • Handlers extensibles, mapping triggers
  • Extensions locales tolérantes (ZBE, Z99)
  • Génération HL7 centralisée (adapters/hl7_pam_fr.py)

4. Points d'intégration et extension

  • Ajout de triggers : mapping HANDLERS + handler
  • Extension validation : pam_validation.py
  • Adaptation parsing : infrastructure/hl7/parsing.py
  • Support nouveaux segments : parsing + validation

5. Limitations et points d'attention

  • Validation HL7 v2.5 partielle : parseur certifié recommandé pour conformité totale
  • Extensions locales : tolérance sandbox, stricte en production
  • Transitions workflow : validées par scénario, cas complexes à ajuster
  • Fusions (A40) : pas de gestion des conflits cliniques/financiers
  • Variables d'environnement : bien vérifier la configuration

6. Références et documentation

  • Spécification IHE PAM France : Doc/IHE_PAM.md
  • Règles HL7 v2.5 : Doc/HL7v2.5/CH02A.pdf, Doc/HL7v2.5/Ch03.pdf
  • Structures HAPI : Doc/HAPI/hapi/custom/message/
  • Documentation utilisateur : Doc/IHE_PAM.md, scripts/validate_pam.py

Pour toute extension ou adaptation, se référer aux modules cités et aux conventions de factorisation et de configuration décrites ci-dessus.
