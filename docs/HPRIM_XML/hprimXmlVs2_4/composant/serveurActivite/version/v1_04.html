Pour <acteCCAM>

  • ajout balise <factureRealisateur>

    • Cette balise permet aux cabinets de radiologie (et autre) de transmettre leur numérotation et ainsi permettre aux cliniques de retourner les règlements avec cette valeur, dans le cadre d'un flux Hprim santé par exemple.

    • éléments associés : <numero> et <date>

  • ajout attribut forfaitSecuriteEnvironnementHospitalier

    • Prestation de "sécurité et environnement hospitalier".


pour <UCD>

  • ajout balise <naturePrestation>

    • balise vide avec un attribut nommé nature prenant les valeurs ph1, ph4, ph7, ph8, phh, phs, phq, phu, phm, php, phi.

  • ajout balise <denomination>

    • Information complémentaire à la codification.

  • ajout balise <codeCommercial>

    • alternative au code UCD pour notamment les médicaments à autorisation temporaire d’utilisation.

  • ajout balise <siretFournisseur>

  • ajout <noLot>

    • Numéro de lot du médicament.

  • ajout attribut essaiTherapeutique

    • valeur oui / non.

  • Pour le type complexe typeProfessionnelSante, ajout balise <noRPPS> alternative de <numeroAdeli>
