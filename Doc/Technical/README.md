# Documentation technique — MedData Bridge

Ce dossier centralise la documentation développeur sur la validation, la
logique métier et l'architecture des services.

Fichiers importants
- `scenario_validation.md` — validation multi-message et règles de workflow.
- `validation.md` — règles message / variables d'environnement et outils.
- `architecture.md` — vue synthétique de l'architecture et des modules.

Principe
- Garder les docs courtes, en français, et alignées sur l'implémentation.
- Mettre à jour ces fichiers à chaque modification des validateurs ou du
  graphe de transitions.
