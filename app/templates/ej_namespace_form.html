📘 Comprendre les namespaces d'identifiants

URI FHIR (system) : Identifiant complet utilisé dans les ressources FHIR.

→ Exemple : urn:oid:1.2.250.1.71.1.2.2

OID HL7v2 : Identifiant court utilisé dans les messages HL7v2 (CX-4 Assigning Authority).

→ Exemple : 1.2.250.1.71.1.2.2 (extrait automatiquement de l'URI)

Nom HL7v2/IHE PAM : Nom court utilisé dans les messages HL7v2 (optionnel).

→ Exemple : CHPAULON (généré automatiquement si non fourni)

💡 Astuce : Vous pouvez réutiliser la même URI pour plusieurs types d'identifiants (ex: IPP, NDA, MVT avec urn:oid:1.2.250.1.71.1.2.2)
