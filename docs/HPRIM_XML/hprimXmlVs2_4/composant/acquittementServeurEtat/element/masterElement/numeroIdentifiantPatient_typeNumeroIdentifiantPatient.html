Sommaire Elément précédent
numeroIdentifiantPatient [typeNumeroIdentifiantPatient]
Identifiant du patient.
Eléments
NomCommentaires
identifiant Valeur alphanumérique de l'identité.
autorite Définition de l'autorité d'affectation de l'identité. Dans le cas de l'INS NIR, l'OID est égal à 1.2.250.1.213.1.4.8, nom = ASIPSANTE-INS-NIR, type = ISO. Pour l'INS NIR de test, l'OID est égal à 1.2.250.1.213.1.4.10, nom = ASIPSANTE-INS-NIA, type = ISO. Pour l'INS NIR de de démonstration, l'OID est égal à 1.2.250.1.213.1.4.11, nom = ASIPSANTE-INS-NIA, type = ISO. Pour l'INS NIA, l'OID est égal à 1.2.250.1.213.1.4.9, nom = ASIPSANTE-INS-NIA, type = ISO.
dateDebutValidite Date de début de validité en vigueur de l’INS. [Elément facultatif]
dateFinValidite Date de fin de validité en vigueur de l’INS. [Elément facultatif]
