extensionTemporaire [typeExtensionTemporaire]
Permet d'ajouter temporairement des données nécessaires localement avant intégration dans la nouvelle version du schéma, ces extensions sont à utiliser avec parcimonie dans des contextes locaux pour une démarche de gré à gré et lorsque l'éditeur emploie ces extensions au delà d'un contexte local, il est judicieux de remonter sa demande auprès d'Interopsante.
