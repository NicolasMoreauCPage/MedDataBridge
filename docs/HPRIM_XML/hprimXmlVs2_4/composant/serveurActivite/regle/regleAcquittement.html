Régles pour les acquittements

Dés l'instant ou le message d'origine a l'attribut acquittementAttendu chargé à oui (attribut présent dans <evenementServeurActe>), cela signifie que le récepteur doit retourner un acquittement correspondant.

Vous retrouverez plus d'information sur le contenu de l'acquittement dans la rubrique dédiée "Acquittement serveur d'activité".
