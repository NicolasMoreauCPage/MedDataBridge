API REST FHIR — Réception et Émission

IntegraSanté expose une API REST complète pour l'export et l'import de données au format FHIR R4, conforme au profil France (hl7.fhir.fr.core).

📖 Documentation complète

Pour la documentation technique détaillée de l'API FHIR (tous les endpoints, exemples, formats), consultez : FHIR_API.html

Émission (Export)

  • ✓ Export de dossiers → Bundle FHIR (Patient, Encounter, EpisodeOfCare)
  • ✓ Export de structure → Bundle FHIR (Location hiérarchique)
  • ✓ Extensions FRCore appliquées (fr-core-encounter, fr-core-patient)
  • ✓ Validation avec HAPI FHIR validator + IG France
  • ✓ fullUrl stables : ResourceType/<id>
Voir les endpoints d'export

Réception (Import)

  • ✓ Import de Bundle FHIR → création/mise à jour entités (Patient, Encounter, Location)
  • ✓ Résolution des références bundle-locales (resource_map partagé)
  • ✓ Support des formats de référence : Type/id, #id, urn:uuid:...
  • ✅ Validation format bundle et contrôle EJ
  • ✅ Tests unitaires et roundtrip validés
→ Voir les endpoints d'import

Endpoints principaux

Export de dossier (Encounter complet)

GET /api/fhir/export/dossiers/{dossier_id}

Retourne un Bundle FHIR contenant Patient, Encounter, EpisodeOfCare et références Location.

Export de structure organisationnelle

GET /api/fhir/export/structure/{ej_id}

Retourne un Bundle FHIR (type transaction) avec la hiérarchie Location (EG, UF, USC, UH, Chambre, Lit).

Import de Bundle FHIR

POST /api/fhir/import/bundle

Importe un Bundle FHIR complet (Patient, Encounter, Location). Résout les références internes et crée/met à jour les entités en base.

Conformité et validation

✓

Profil French Core (hl7.fhir.fr.core): Les ressources émises incluent les extensions et profils FRCore requis.

✓

Validation HAPI: Les bundles générés sont validés avec le validateur HAPI FHIR + IG pack French Core.

✓

Roundtrip testé: Un bundle émis peut être réimporté sans perte de données (tests unitaires en place).

✓

Références robustes: L'import gère les URL complètes, les références Type/id, les références #id, et les URN uuid.
