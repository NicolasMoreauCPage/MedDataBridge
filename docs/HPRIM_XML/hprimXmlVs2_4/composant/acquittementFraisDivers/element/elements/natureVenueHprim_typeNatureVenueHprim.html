natureVenueHprim [typeNatureVenueHprim]
Type comportant un attribut optionnel "valeur" contenant l'une des natures possibles pour une venue, dans le dictionnaire Hprim, et/ou un [code, libelle] issus d'un autre dictionnaire. L'élément fils "accompagne" est utilisé lorsque la nature vaut "acc" = accompagnant. Dans ce cas, l'élément "patient" dans l'événement décrit l'accompagnant, et l'élément "accompagne" référence le patient accompagné.
