Version 1.02

Modifications apportées suite à la réunion du 11/03/2004 sous l’égide du GMSIH.

  • Précision sur le contenu <evenementServeurActe> pour le choix des balises <actesCCAM> et <actesNGAP>

  • Précision sur le contenu <identifiant> pour l’intervention, demande, acte CCAM, acte NGAP, identifiantActePrincipal

  • Modification de la cardinalité des balises <evenementServeurIntervention>, <evenementServeurActe>, <evenementFusionIntervention>

    • cardinalité a 1

  • Ajout balise <priseCharge> pour les actes NGAP

  • Prise en compte du lien entre geste complémentaire et acte principal

    • Ajout balise <identifiantActePrincipal> et ses filles

  • Mise en place d’un message d’acquittement sur serveur d’actes version 1.020

    • l’attribut codeErreur de la balise <reponse> donne la possibilité d’émettre un code erreur référencé dans une liste finie Hprim.
