À propos de la configuration des scénarios

Cette configuration permet de définir les UF et médecins qui seront utilisés lors de l'exécution des scénarios d'interopérabilité vers les endpoints associés à chaque EJ.

  • UF Hospitalisation: Utilisée pour les admissions (A01), sorties (A03)
  • UF Consultation: Utilisée pour les consultations externes (A04)
  • UF Urgences: Utilisée pour les passages aux urgences
  • UF Mutation: UF destination pour les transferts (A02)

Pour chaque type d'UF, vous pouvez également associer un médecin (numéro RPPS) qui sera injecté dans les messages HL7 (PV1-7 médecin référent, PV1-17 médecin traitant).
