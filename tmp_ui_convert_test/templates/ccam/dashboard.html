Informations CCAM

La Classification Commune des Actes Médicaux (CCAM) est la nomenclature des actes médicaux et chirurgicaux réalisée par les professionnels de santé.

  • Codes actes : 4 lettres + 3 chiffres (ex: HBQK003)
  • Codes activité : 2 chiffres pour la modalité de réalisation
  • Codes phase : 2 chiffres optionnels pour les actes en plusieurs phases
  • Modificateurs : lettres pour préciser les conditions de réalisation
  • Extension : code optionnel pour actes particuliers
