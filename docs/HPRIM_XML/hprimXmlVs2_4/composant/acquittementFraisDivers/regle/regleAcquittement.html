Régles pour les acquittements

L’utilisation de l’acquittement est conditionnée par l'alimentation de l'attribut acquittementAttendu à oui dans le message d'origine émis, présent sur la balise maitre.

L’indicateur d’acquittement du message est l’attribut obligatoire statut situé sur la balise enteteMessageAcquittement. Il porte sur la validation de l’ensemble des réponses emis dans l'acquittement. Il existe 2 niveaux de refus :
  • global, le message émis initialement est refusé dans son ensemble.Il s'agit notamment des valeurs rj (Rejet) et ncs (Non conforme au schéma)
  • unitaire, à savoir au moins une réponse porte ce statut. L'ordre décroissant d'importance des valeurs est le suivant :
    • err (Erreur)
    • avt (Avertissement)
    Pour exemple, si au moins une réponse est en erreur, le statut prend comme valeur err.
