📘 Comprendre les namespaces d'identifiants

En HL7v2 (messages reçus/envoyés) : Le namespace est composé de NOM + OID

→ Format reçu : CHPAULON&1.2.250.1.71.1.2.2&ISO

→ Peut être aussi : CHPAULON (nom seul) ou 1.2.250.1.71.1.2.2 (OID seul)

⚠️ On ne reçoit jamais d'URI en HL7v2

En FHIR (ressources reçues/envoyées) : Le namespace est une URI uniquement

→ Format envoyé : urn:oid:1.2.250.1.71.1.2.2

⚠️ On n'envoie pas le nom ni l'OID séparément en FHIR

💡 Astuce : Vous pouvez réutiliser la même URI pour plusieurs types d'identifiants (ex: IPP, NDA, MVT avec urn:oid:1.2.250.1.71.1.2.2)
